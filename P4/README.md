# P4 — GitHub README and version tags

**Aim:** Explain the project and create a version tag.

A README tells people what the project does, which files it has and how to open it.

After committing your work:
```bash
git tag -a v1.0 -m "First lab version"
git tag
git push origin v1.0
```

A tag marks a particular commit so you can find that version later.

# P1 — Project folder and terminal navigation

**Aim:** Make a project folder and practise terminal commands.

Run one by one:
```bash
pwd
mkdir my-web-lab
cd my-web-lab
mkdir images css
touch index.html
ls
cd css
pwd
cd ..
cd ..
```
- `pwd` shows where you are.
- `mkdir` creates a folder.
- `cd` moves into a folder.
- `touch` creates a file.
- `ls` shows the files.

Folder made: `my-web-lab/images`, `my-web-lab/css`, and `my-web-lab/index.html`.

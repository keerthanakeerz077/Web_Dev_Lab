# P2 — Portfolio repo with an initial commit

**Aim:** Save the first version of your portfolio using Git.

```bash
git init
git status
git add .
git commit -m "First portfolio commit"
git branch -M main
```

Connect it to GitHub:
```bash
git remote add origin https://github.com/keerthanakeerz077/Web_Dev_Lab.git
git push -u origin main
```
If origin already exists, check it using `git remote -v` instead of adding it again.
